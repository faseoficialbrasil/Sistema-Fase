Como Funciona - Fluxo D+5 Oficial

1. T-72h/48h - 3 PIX

Cliente quita 3 PIX separados. Sem comprovante BEF = não implanta equipe. 1 PIX único = estorna Art.37 fiscal.

2. Dia D T+30/T+120 - Fotos

Supervisor blazer posta 3 fotos T+30 + 3 fotos T+120 no grupo cliente. Prova padrão Fasano. Sem foto = G-05 = trava comissão.

3. Se NC - Foto Antes/Depois

NC Crítica = foto correção T+35min grupo + texto Correção C-__ agora padrão Fasano. NC Grave = T+45min. Sem foto = comissão travada.

4. D+5 - Liberação Comissão CNPJ 15%

Financeiro confere 8 checks: Fotos grupo + BEF + 3 PIX + Sem NC aberta + NF CNPJ + Calculadora V3.2 DRE líquida R$610-R$3.050 + Caixa R$4.040 + REG 1p. OK = paga PIX CNPJ.
